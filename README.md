# 짤깍 · JJALKKAK

한국어로 GIF를 검색하고, 대화에 답장할 GIF를 추천받는 데스크톱 검색창입니다.

```bash
npm ci
npm run dev
```

브라우저에서 http://127.0.0.1:5173/ 을 열면 샘플 GIF로 화면을 확인할 수 있습니다. 브라우저에서 GIF를 클릭하면 클립보드에 복사합니다.

데스크톱은 Vite를 실행한 상태에서 다른 터미널에 `npm run desktop`을 실행합니다. macOS에서 파일 클립보드를 사용하려면 Swift 컴파일러가 필요합니다. 앱을 처음 시작하면 패널이 열리고, 이후에는 맥 `⌥ Space` 또는 Windows `Alt+Space`로 다시 엽니다. GIF를 클릭하거나 방향키로 선택 후 Enter를 누르면 파일이 복사되고 패널이 닫힙니다. 카카오톡에서 `⌘V` 또는 `Ctrl+V`로 붙여넣습니다. 카드에서 파일을 끌어다 놓을 수도 있습니다.

## Vercel 배포

저장소 루트에서 Vite로 빌드합니다. 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다.
배포 화면 하단의 `KLIPY 설정`을 열고 KLIPY 웹 클라이언트용 앱 키를 입력합니다.
키는 열린 브라우저 탭이 메모리에 보관하며 KLIPY 요청에만 사용합니다. 새로고침하면 샘플 모드로 돌아갑니다.

브라우저에서 보이는 단축키 안내는 데스크톱 앱을 위한 것입니다. 웹에서는 브라우저가 지원하는 경우 원본 GIF를 복사하고, 그 외에는 PNG 정지 이미지로 복사합니다.
문자 추천은 기본적으로 기기 내 키워드 규칙을 사용하며, 실시간 모드에서는 해당 검색어로 KLIPY 결과를 조회합니다.

## 실시간 검색과 로컬 AI

- 샘플 모드에서 검색과 추천을 바로 시연할 수 있습니다.
- KLIPY 실시간 검색은 `.env.example`을 `.env.local`로 복사하고 `VITE_GIF_MODE=live` 및 발급받은 `VITE_KLIPY_KEY`를 설정한 뒤 로컬 Electron과 Vite를 다시 시작합니다.
- Electron에서 로컬 Ollama를 실행하고 설치한 모델 이름을 `VITE_OLLAMA_MODEL`에 지정하면 메시지의 감정과 맥락을 분석해 영어 검색어를 만듭니다. KLIPY에는 이 검색어가 전달됩니다. 기본 모드의 대화 추천은 기기 내 키워드 규칙을 사용합니다.
- `npm run build`로 타입 검사와 웹 빌드를 실행합니다.

## 카카오톡 GIF 복사 방식 비교

macOS에서 같은 GIF를 원본 바이트와 파일 객체로 각각 복사해 붙여넣기 결과를 비교합니다.

```bash
bash run-gif-test.sh
```

Swift 컴파일러가 필요합니다. 터미널에서 설치 안내가 나오면 `xcode-select --install`을 실행한 뒤 다시 시작하세요.

1. **A. 원본 GIF 복사**를 누르고 맥 카카오톡 테스트 채팅방에서 `⌘V`로 붙여넣습니다.
2. 붙여넣어진 형태를 확인하고 전송합니다. 받는 사람 화면에서 숫자 **1 → 2 → 3**이 반복되는지 확인합니다.
3. **B. GIF 파일 복사**로 같은 절차를 반복합니다. 파일로 보내졌다면 채팅 화면과 파일을 열었을 때의 재생 여부를 구분해서 기록합니다.

| 복사 방식 | 붙여넣기 결과 (이미지 / 파일 / 변화 없음) | 수신 화면에서 재생 | 파일을 열면 재생 |
| --- | --- | --- | --- |
| A. 원본 GIF 바이트 | | | |
| B. `.gif` 파일 객체 | | | |

B는 저장소 안의 `fixtures/123.gif`를 참조합니다. 붙여넣는 동안 해당 파일이 있어야 합니다. `bash run-gif-test.sh --check`는 별도 클립보드를 사용해 두 복사 형식과 GIF 프레임 수를 확인합니다.
